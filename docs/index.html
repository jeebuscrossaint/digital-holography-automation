Photonic Lantern Digital Holography Automation

Measuring the wavelength-dependent transfer matrix of a photonic lantern by off-axis digital holography — fully automated, from hardware control to complex-field reconstruction.

View on GitHub → How it works

What this is

A photonic lantern couples an array of single-mode fibers to the guided modes of a multimode fiber. That mapping is a complex-valued transfer matrix — and in non-mode-selective lanterns it evolves strongly with wavelength. Measuring it requires recovering both the amplitude and phase of the field emerging from the multimode facet for every input port at every wavelength.

Done by hand, that's hours of alignment and tuning per session. This software automates the whole loop — instrument control, polarization optimization, hologram capture, and field reconstruction — so a full port × wavelength sweep runs essentially unattended.

Method based on: "Wavelength-dependent evolution of full-field transfer matrices in photonic lanterns," C. Dobias et al., Optics Express 34(9), 17217 (2026). doi:10.1364/OE.595908

How it works

01

Acquire

For each lantern port (fiber switch) and wavelength (tunable laser), auto-optimize polarization for fringe contrast, then capture the off-axis hologram. Clipped/saturated frames are rejected.

02

Reconstruct

FFT the hologram, isolate the off-axis sideband, demodulate to baseband, low-pass (Butterworth), and inverse-FFT to the complex field — optimizing mode diameter, quadratic phase, and position.

03

Decompose

Project the recovered field onto the LP-mode basis to get the modal coefficients — one row of the transfer matrix — with a fidelity metric and per-hologram analysis plots.

Features

  • One-click connect / safe shutdown of all four instruments
  • Unattended port × wavelength acquisition with live camera preview
  • Carrier-locked FFT sideband metric + automatic polarization optimization
  • Saturation rejection so clipped holograms never enter the dataset
  • Off-axis field reconstruction and LP-mode decomposition with fidelity
  • Single YAML config for instrument addresses and sweep parameters

Run it

Ships as a single native Windows executable — no Python, Node, or server needed on the lab machine:

# build the app
uv run python tools/build_app.py     # -> dist/Digital Holography.exe

# or run from source (needs uv)
uv sync && ./start.bat

See LAB_SETUP.md for one-time machine setup (Keysight IO Libraries, Xenics Xeneth SDK, camera firewall rule).
